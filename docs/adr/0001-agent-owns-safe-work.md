# Agent owns all safe work

MOX-ADV is AI-first: the agent completes every permitted, bounded, reversible or containable, observable task for which it has sufficient evidence. It must research allowed sources, synthesize a proposed result, execute routine work inside the active Mandate, and preserve evidence without turning those steps into operator forms. A named human receives a prepared decision packet only when authority must be granted or expanded, consequences are materially irreversible, the active Mandate would be exceeded, or unresolved uncertainty can materially change the business outcome.

## Consequences

- Discoverable facts are agent inputs, not required human fields.
- Low-risk missing data triggers more autonomous research before escalation.
- A Human Decision Gate shows the agent's recommendation, evidence, confidence, alternatives, and consequences; it is never a blank questionnaire.
- External actions are not automatically human-owned: bounded actions within an approved Mandate remain Agent-Owned Work, while authority changes and material exposure remain human-owned.
